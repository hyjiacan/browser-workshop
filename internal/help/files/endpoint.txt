================================================================================
                          bws endpoint - 输出实例端点
================================================================================

【命令说明】
  endpoint 命令用于输出指定后台实例的 CDP / WebDriver 端点，
  供 Playwright、Puppeteer、Selenium、WebdriverIO 等框架连接。

【命令格式】
  bws endpoint <实例名> [选项]

【选项参数】
  ┌──────────────────────┬──────────┬────────────────────────────────────────┐
  │ 选项                 │ 默认值   │ 说明                                   │
  ├──────────────────────┼──────────┼────────────────────────────────────────┤
  │ --json               │ false    │ 以 JSON 格式输出                       │
  └──────────────────────┴──────────┴────────────────────────────────────────┘

【使用示例】

  1. 输出实例端点：
     bws endpoint bws-chrome-120-test-01

  2. JSON 输出：
     bws endpoint bws-chrome-120 --json

【输出示例】
  CDP:       ws://127.0.0.1:54321/devtools/browser/xxxxx
  WebDriver: http://127.0.0.1:9515

【注意事项】
  * 实例名可通过 bws ps 查看，通过 bws r ... --daemon 创建。
  * 实例不存在时返回非 0 退出码。
  * 不可用的端点不会输出（对应字段为 null）。
