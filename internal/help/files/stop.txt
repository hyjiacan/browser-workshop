================================================================================
                          bws stop - 停止后台实例
================================================================================

【命令说明】
  stop 命令用于停止运行中的后台实例，并从实例注册表中移除对应条目。
  Profile 数据不会被删除。

【命令格式】
  bws stop <实例名> [选项]
  bws stop --all [选项]

【选项参数】
  ┌──────────────────────┬──────────┬────────────────────────────────────────┐
  │ 选项                 │ 默认值   │ 说明                                   │
  ├──────────────────────┼──────────┼────────────────────────────────────────┤
  │ --all, -a            │ false    │ 停止所有实例                           │
  │ --json               │ false    │ 以 JSON 格式输出                       │
  └──────────────────────┴──────────┴────────────────────────────────────────┘

【使用示例】

  1. 停止指定实例：
     bws stop bws-chrome-120-test-01

  2. 停止所有实例：
     bws stop --all

  3. JSON 输出：
     bws stop --all --json

【行为说明】
  * 先尝试优雅退出，超时后强制终止。
  * 若实例关联了 chromedriver，一并停止。
  * 从实例注册表移除条目；Profile 数据保留，可复用或手动清理。
  * 进程已退出但注册表未清理时，输出 Stopped: <name> (already exited)。
  * 实例不存在时报错，退出码非 0。
  * JSON 输出包含 stopped 与 failed 两个数组。
