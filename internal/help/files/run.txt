================================================================================
                          bws run - 运行浏览器
================================================================================

【命令说明】
  run 命令用于运行指定版本的浏览器。支持多种运行模式和选项，
  包括无头模式、隐身模式、指定 Profile、指纹隔离等。

【命令格式】
  bws r [浏览器[@版本]] [URL] [选项] [-- 原生参数]

【选项参数】
  ┌──────────────────────┬──────────┬────────────────────────────────────────┐
  │ 选项                 │ 默认值   │ 说明                                   │
  ├──────────────────────┼──────────┼────────────────────────────────────────┤
  │ --headless, -H       │ false    │ 无头模式运行                           │
  │ --incognito, -i      │ false    │ 隐身/无痕模式运行                      │
  │ --new-window, -w     │ false    │ 在新窗口中打开                         │
  │ --profile, -p        │ -        │ 使用指定的 Profile 名称                │
  │ --native, -n         │ false    │ 原生模式启动（无 bws 隔离）            │
  │ --detached, -d       │ false    │ 后台运行（不等待进程结束）             │
  │ --dry-run            │ false    │ 仅打印命令，不实际运行                 │
  │ --proxy              │ -        │ 代理地址（留空使用全局配置）           │
  │ --no-proxy           │ false    │ 禁用代理（覆盖全局配置）               │
  │ --fingerprint, -fp   │ -        │ 指纹隔离预设（standard/random/none）   │
  │ --plugin             │ -        │ 激活的插件（逗号分隔多个）             │
  │ --automation         │ false    │ 自动化模式：注入 CDP 参数并管理驱动     │
  │ --cdp                │ false    │ 启用 CDP 端点（automation 子集）       │
  │ --webdriver          │ false    │ 启用 WebDriver 端点（automation 子集） │
  │ --daemon             │ false    │ 后台运行并登记为可管理实例             │
  │ --driver-port        │ 0        │ chromedriver 监听端口（0 表示自动）    │
  │ --driver-no-download │ false    │ 自动化模式下不自动下载驱动             │
  │ --endpoint-timeout   │ 10       │ 端点发现超时（秒）                     │
  │ --json               │ false    │ 以 JSON 格式输出启动契约               │
  └──────────────────────┴──────────┴────────────────────────────────────────┘

【使用示例】

  1. 运行指定版本：
     bws r chrome@120

  2. 运行系统版本：
     bws r chrome@system

  3. 运行默认版本：
     bws r chrome

  4. 打开指定 URL：
     bws r chrome@120 https://example.com

  5. 无头模式：
     bws r chrome@120 -H

  6. 隐身模式：
     bws r chrome@120 -i

  7. 指定命名 Profile：
     bws r chrome@120 -p work

  8. 后台运行：
     bws r chrome@120 -d

  9. 传递原生参数：
     bws r chrome@120 -- --disable-gpu --no-sandbox

  10. 试运行：
      bws r chrome@120 --dry-run

  11. 使用代理：
      bws r chrome@120 --proxy socks5://127.0.0.1:1080

  12. 禁用代理：
      bws r chrome@120 --no-proxy

  13. 指纹隔离（随机）：
      bws r chrome@120 --fingerprint random

  14. 指纹隔离（标准）：
      bws r chrome@120 --fingerprint standard

  15. 使用插件：
      bws r chrome@120 --plugin auto-arg
      bws r chrome@120 --plugin auto-arg,fingerprint-enhanced

  16. 自动化模式（注入 CDP 参数并自动管理匹配版本的 chromedriver）：
      bws r chrome@120 --automation

  17. 自动化模式并指定驱动端口：
      bws r chrome@120 --automation --driver-port 9515

  18. 仅启用 CDP 端点：
      bws r chrome@120 --cdp

  19. 仅启用 WebDriver 端点：
      bws r chrome@120 --webdriver

  20. 后台运行并登记为可管理实例：
      bws r chrome@120 --automation --daemon --profile test-01

  21. 自动化模式 + JSON 输出：
      bws r chrome@120 --automation --json

  22. 自动化模式下禁止自动下载驱动：
      bws r chrome@120 --automation --driver-no-download

【自动化模式说明】
  --automation 是自动化能力的超集开关，会按以下流程准备：
    1. 解析本次启动的 Chrome 版本（如 120.x.x.x）
    2. 注入 --remote-debugging-port=0、--remote-debugging-address=127.0.0.1、
       --disable-blink-features=AutomationControlled
    3. 启动浏览器，从 Profile 目录的 DevToolsActivePort 文件（回退
       GET /json/version）发现 CDP 端点
    4. 查询 Chrome for Testing 清单，下载并解压 chromedriver 到
       bws-data/drivers/chromedriver/120/
    5. 启动 chromedriver 并监听端口，输出 WebDriver 端点

  Playwright / Puppeteer 可通过 CDP 端点连接，Selenium / WebdriverIO
  可通过 WebDriver 端点连接。

  * --cdp / --webdriver 是 --automation 的子集（可单独使用）。
  * --daemon 等价于「后台运行 + 登记实例注册表」，可配合 ps / stop 管理。
  * 用户显式传入的 --remote-debugging-port 等参数优先，不被覆盖。
  * 端点发现超时或驱动启动失败不会中断浏览器启动，仅在标准错误输出
    告警，对应字段输出 null。
  * 配置了 serve 离线源时，将优先通过 serve 解析并下载驱动。

【注意事项】
  * 省略版本号时使用默认版本（可通过 bws u 设置）。
  * -- 之后的参数原样传递给浏览器，可用于传递任何原生参数。
  * 后台运行模式下，bws 不会等待浏览器进程结束即返回。
  * CDP 端点仅支持 Chrome/Chromium/Edge；WebDriver 目前仅托管
    Chrome/Chromium 的 chromedriver。
  * 完整接入指南请参考 docs/guide/automation.md。
