================================================================================
                          bws where - 输出浏览器本地路径
================================================================================

【命令说明】
  where 命令用于输出浏览器的本地路径（二进制 / 安装目录 / Profile），
  主要用于命令替换场景，例如让 Cypress 使用 bws 管理的浏览器：
      cypress run --browser "$(bws where chrome@120)"

【命令格式】
  bws where <浏览器[@版本]> [选项]

【选项参数】
  ┌──────────────────────┬──────────┬────────────────────────────────────────┐
  │ 选项                 │ 默认值   │ 说明                                   │
  ├──────────────────────┼──────────┼────────────────────────────────────────┤
  │ --dir                │ false    │ 输出安装目录而非二进制路径             │
  │ --profile            │ false    │ 输出 Profile 目录                      │
  │ --profile-name       │ -        │ 指定 Profile 名称（与 --profile 配合） │
  │ --json               │ false    │ 以 JSON 格式输出                       │
  └──────────────────────┴──────────┴────────────────────────────────────────┘

【使用示例】

  1. 默认输出二进制路径（便于命令替换）：
     bws where chrome@120

  2. 输出安装目录：
     bws where chrome@120 --dir

  3. 输出 Profile 目录：
     bws where chrome@120 --profile --profile-name test-01

  4. JSON 输出：
     bws where chrome@120 --json

【JSON 输出结构】
  {
    "ok": true,
    "command": "where",
    "data": {
      "browser": "chrome",
      "version": "120.0.6099.109",
      "binary": "...\\versions\\chrome\\120.0.6099.109\\chrome.exe",
      "dir": "...\\versions\\chrome\\120.0.6099.109",
      "profile": "...\\runtime\\chrome\\120.0.6099.109\\test-01"
    }
  }

【注意事项】
  * 默认只向 stdout 输出路径本身，不含任何额外提示，便于命令替换。
  * 版本未安装或找不到可执行文件时返回非 0 退出码。
