================================================================================
                          bws ps - 列出运行中的后台实例
================================================================================

【命令说明】
  ps 命令用于列出由 bws r --daemon 启动并登记到实例注册表的后台实例。
  与 ls 互不重叠：ls 列出磁盘上已安装的版本，ps 列出运行中的进程。

【命令格式】
  bws ps [选项]

【选项参数】
  ┌──────────────────────┬──────────┬────────────────────────────────────────┐
  │ 选项                 │ 默认值   │ 说明                                   │
  ├──────────────────────┼──────────┼────────────────────────────────────────┤
  │ --json               │ false    │ 以 JSON 格式输出                       │
  └──────────────────────┴──────────┴────────────────────────────────────────┘

【使用示例】

  1. 列出运行中的实例：
     bws ps

  2. JSON 输出：
     bws ps --json

【输出示例】
  NAME                     BROWSER   VERSION          PROFILE   PID     CDP
  bws-chrome-120-test-01   chrome    120.0.6099.109   test-01   12345   ws://127.0.0.1:54321/…

【注意事项】
  * 无实例时输出 No running instances.
  * 查询时校验 PID 存活，已退出的僵尸条目自动清理并告警到 stderr。
  * 表格中的 CDP 会截断显示，完整值请用 --json 或 bws endpoint。
