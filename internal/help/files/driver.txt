================================================================================
                        bws driver - 自动化驱动管理
================================================================================

【命令说明】
  driver 命令用于管理自动化驱动（目前为 chromedriver）。

  自动化驱动的版本与浏览器版本强绑定：一个 chromedriver 只能驱动主版本
  相同的 Chrome/Chromium。因此 bws 不内置固定版本，而是按需解析、下载
  并启动匹配版本的驱动。

  解析流程：
    1. 用户执行 bws r chrome@120 --automation
    2. bws 得到 Chrome 版本 120.x.x.x
    3. 查询 Chrome for Testing 清单，找到 120.x.x.x 对应的下载地址
    4. 下载并解压到 bws-data/drivers/chromedriver/120/
    5. 启动 chromedriver 进程并监听端口，输出 WebDriver 端点

【数据源】
  ┌──────────────────┬──────────────────────────────────────────────┐
  │ Chrome 版本       │ 数据源                                       │
  ├──────────────────┼──────────────────────────────────────────────┤
  │ >= 115           │ Chrome for Testing 已知版本清单               │
  │                  │ known-good-versions-with-downloads.json      │
  │ < 115            │ 旧版 chromedriver storage 存储桶             │
  └──────────────────┴──────────────────────────────────────────────┘

  当配置了 serve 离线源（bws cfg set source <url>）时，bws 会优先通过
  serve 解析并下载驱动，便于内网/离线环境分发。

【命令格式】
  bws driver <子命令> [参数] [选项]

【子命令】
  ┌────────────┬──────────────────────────────────────────────────┐
  │ 子命令      │ 说明                                             │
  ├────────────┼──────────────────────────────────────────────────┤
  │ ls         │ 列出已安装的驱动                                  │
  │ install    │ 下载并安装匹配指定 Chrome 版本的驱动              │
  │ start      │ 启动已安装的驱动并监听端口                        │
  │ uninstall  │ 卸载指定主版本的驱动                              │
  └────────────┴──────────────────────────────────────────────────┘

【选项参数】

  driver install：
  ┌───────────────┬──────────┬────────────────────────────────────┐
  │ 选项          │ 默认值   │ 说明                               │
  ├───────────────┼──────────┼────────────────────────────────────┤
  │ --force, -f   │ false    │ 强制重新安装                       │
  │ --dry-run     │ false    │ 仅解析并显示下载信息，不实际安装   │
  └───────────────┴──────────┴────────────────────────────────────┘

  driver start：
  ┌────────────────┬──────────┬────────────────────────────────────┐
  │ 选项           │ 默认值   │ 说明                               │
  ├────────────────┼──────────┼────────────────────────────────────┤
  │ --port, -p     │ 0        │ 监听端口（0 表示自动分配）         │
  │ --detach, -d   │ false    │ 后台运行（不等待进程结束）         │
  │ --allowed-ips  │ 127.0.0.1│ 允许连接的 IP                      │
  │ --log          │ -        │ 驱动日志文件路径                   │
  └────────────────┴──────────┴────────────────────────────────────┘

  driver uninstall：
  ┌───────────────┬──────────┬────────────────────────────────────┐
  │ 选项          │ 默认值   │ 说明                               │
  ├───────────────┼──────────┼────────────────────────────────────┤
  │ --force, -f   │ false    │ 跳过确认直接卸载                   │
  └───────────────┴──────────┴────────────────────────────────────┘

【使用示例】

  1. 列出已安装的驱动：
     bws driver ls
     bws drv ls

  2. 安装匹配 Chrome 120 的驱动：
     bws driver install chrome@120

  3. 仅解析并显示下载信息：
     bws driver install 120 --dry-run

  4. 强制重新安装：
     bws driver install chrome@120 --force

  5. 启动驱动（自动分配端口）：
     bws driver start 120

  6. 启动驱动并指定端口：
     bws driver start chrome@120 --port 9515

  7. 后台启动驱动：
     bws driver start 120 --detach

  8. 卸载驱动：
     bws driver uninstall 120

【与 run 命令配合】
  使用 bws r 的 --automation 选项可在启动浏览器的同时自动管理驱动：

    bws r chrome@120 --automation

  bws 会自动安装并启动匹配的 chromedriver，然后输出 WebDriver 端点，
  Selenium / WebdriverIO 等框架即可连接。

【目录结构】
  bws-data/drivers/chromedriver/<主版本>/
  例如：bws-data/drivers/chromedriver/120/

  每个主版本目录下保存该主版本对应的驱动可执行文件及元数据
  （.bws-driver.json），元数据记录了精确版本号、平台、安装时间等。
